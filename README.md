 ## Portal de Notícias UNICID

Site de notícias criado com HTML e CSS como trabalho da faculdade.

Site publicado: https://gustavo-lima7.github.io/Portal-de-noticia/

## O que tem no projeto

- Página com cabeçalho, duas notícias em "caixas" e rodapé
- Layout estilizado com CSS (flexbox)
- Efeito de animação ao passar o mouse sobre cada notícia
- Ao clicar na "caixa" de noticia o site redireciona para sites da faculdade

## Tecnologias

- HTML5
- CSS3
